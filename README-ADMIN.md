# Как редактировать сайт и добавлять статьи

## Публикация сайта

Сайт публикуется GitHub Pages из ветки `main`. При изменениях в репозитории GitHub Pages автоматически собирает сайт через Jekyll. Конфигурация сайта находится в `_config.yml`, шаблон — в `_layouts/`, стили — в `assets/site.css`.

## Добавление статей через Pages CMS

1. Войдите на <https://app.pagescms.org> через GitHub.
2. Разрешите Pages CMS доступ к репозиторию `codeFailed/1win` через GitHub App.
3. Откройте репозиторий и ветку `main`. Конфигурация редактора уже находится в `.pages.yml`.
4. Выберите коллекцию **Статьи** и создайте запись.
5. Заполните заголовок, краткое описание, короткий адрес латиницей, дату и текст.
6. Сохраните/закоммитьте запись. Файл появится в `articles/`, GitHub Pages соберёт страницу `/articles/АДРЕС/`, добавит её в автоматически созданный sitemap, а список статей обновится.

Пример адреса: slug `proverka-novogo-adresa` → `/articles/proverka-novogo-adresa/`.

## Добавление дополнительной страницы через Pages CMS

1. В панели выберите **Дополнительные страницы** → создать запись.
2. Заполните заголовок, описание, slug, адрес страницы и текст.
3. Например, укажите slug `pravila-bonusa` и адрес `/pravila-bonusa/`.
4. Сохраните запись. Она появится в `_resources/`, будет опубликована по указанному адресу и попадёт в sitemap после сборки.

## Основные страницы

Главная — `index.html`; основные справочные страницы находятся в корне (`about.html`, `licensing.html`, `terms.html`, `payments.html`, `security.html`, `support.html`, `reviews.html`, `faq.html`, `articles.html`). Статьи и дополнительные страницы можно создавать через Pages CMS без ручной правки HTML.

## Важно

Проверяйте факты и дату обновления, особенно в вопросах лицензирования, региональной доступности, платежей и акций. Не публикуйте вымышленные отзывы и не обозначайте ресурс как официальный без подтверждения. Не размещайте в статьях персональные данные, пароли или платёжную информацию.
